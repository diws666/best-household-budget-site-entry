# Rumah Tangga — best-household-budget-site-20261126-1457

make.fun competition entry: a household budget site for an Indonesian household.
Static files under `app/` only, no build step, zero network requests, state in
`localStorage`. Served locally with `node serve.ts` (http://localhost:8080).

Pages (hash routes): Beranda (`#/`), Pengeluaran (`#/pengeluaran`),
Pemasukan (`#/pemasukan`), Tabungan (`#/tabungan`), Tagihan (`#/tagihan`),
Laporan (`#/laporan`). Rupiah figures for November 2026: income Rp 8.500.000,
expenses Rp 5.000.000 across five categories, sisa Rp 3.500.000, savings goals
and a Jun–Nov 2026 trend chart.
